# PureNet – Erste Schritte

Ziel des QR-Codes innen im Deckel der PureNet-Box:
https://huberindustries.github.io/purenet/start/

Diese Adresse ist auf die Box gedruckt. Repo-Name `purenet` und Ordner `start/` bitte nicht umbenennen.

- `start/index.html` – die Seite (Deutsch, Italiano, English)
- `start/sw.js` – hält eine Offline-Kopie, falls das Handy beim Einrichten im WLAN „PureNet-Setup“ ohne Internet hängt
- `index.html` – leitet auf `start/` weiter
